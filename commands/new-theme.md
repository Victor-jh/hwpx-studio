# /new-theme — 테마 생성

새 테마(기호체계 + 시각서식 + 작성스타일)를 대화형으로 생성합니다.

## 사용법

```
/new-theme                       → 처음부터 구성
/new-theme --from kcup-ryu-yj    → 기존 테마 복제 후 수정
```

## 동작

1. `skills/theme-manager/SKILL.md`를 읽고 "테마 생성" 워크플로우를 따릅니다.
2. 기호체계 → 시각서식 → 작성스타일 순서로 구성합니다.
