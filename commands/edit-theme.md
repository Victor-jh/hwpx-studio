# /edit-theme — 테마 수정

기존 테마의 특정 레이어만 변경합니다.

## 사용법

```
/edit-theme kcup-ryu-yj          → 해당 테마 로드 후 수정
/edit-theme                      → 테마 목록에서 선택
```

## 동작

1. `skills/theme-manager/SKILL.md`를 읽고 "테마 수정" 워크플로우를 따릅니다.
2. 기존 테마를 로드하고, 사용자가 요청한 부분만 변경합니다.
