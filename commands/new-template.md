# /new-template — 양식 생성

새 문서 양식(섹션 순서, 블록 배치)을 대화형으로 생성합니다.

## 사용법

```
/new-template                    → 처음부터 구성
/new-template 예산 검토 보고서     → 이름 지정하여 시작
```

## 동작

1. `skills/template-manager/SKILL.md`를 읽고 "양식 생성" 워크플로우를 따릅니다.
2. 표지 → 섹션 구성 → 파일명 규칙 순서로 구성합니다.
